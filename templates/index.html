Instructions
Drag modules from the repository into the rack.
Hover over repository images to see a magnified preview.
Search the repository by filename or HP value.
Drag existing modules between towers and rows.
Modules snap to the nearest HP position.
Green preview indicates a valid position.
Red preview indicates an invalid position.
Existing modules never move automatically.
Multiple instances of the same module are supported.
Use the red X button to remove a module.
Empty spaces are preserved.
Modules cannot overlap.
Each row is limited to the configured HP capacity.
